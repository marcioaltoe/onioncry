# Render diagnostics without miette

OnionCry declared `miette` from the MVP but never used it: operational errors are a `thiserror` enum printed as one `error:` line on stderr with exit code 2, and check reports are rendered by OnionCry's own pretty, JSON, SARIF and LLM renderers, whose text is public API. We remove the dependency and record that diagnostics stay on these renderers. Removing it changes no output or binary behavior, drops `miette`, `miette-derive` and `unicode-width` 0.1 from the build, and avoids adopting a crate with no release or maintainer activity since April 2025. We rejected adopting `miette` for stderr errors or reports, because it would change asserted public text for a mostly cosmetic gain: config errors already report the line and column. If source snippets become a real need, evaluate an actively maintained renderer such as `annotate-snippets` in a new ADR.
