# A mutation's meta.invalidates declares its invalidation contract

A `useMutation` call whose options object declares `meta.invalidates` satisfies the invalidation requirement of `frontend/feature-system-query-contract`. An empty list declares a mutation that writes nothing the cache holds, such as a file export. This follows the pattern the TanStack Query maintainer publishes for invalidation driven by a global `MutationCache`, where `{ invalidates: [] }` opts a mutation out. The contract lives in the hook's own code, so the `.onioncryrc.jsonc` shape does not change. We rejected a rule option that lists exempt files, because it changes public configuration and separates the exemption from the code it describes. We also rejected relying on per-file overrides alone, because an override disables every query-contract check in that file.
