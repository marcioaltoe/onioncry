# Artifact suffixes classify roles but never exempt placement

An Artifact Filename Suffix such as `.use-case.ts` identifies a Clean Architecture artifact's role. It never exempts the file from `cleanarch/artifact-placement`. A file classified only by its suffix, with no configured artifact folder anywhere in its path, must still sit in an artifact folder of its role's layer, exactly as an unsuffixed file in the same place must. Each placement already followed this rule except the Context-First Clean Architecture Layout, where a suffixed file directly in `src/contexts/<context>/<layer>/` passed while the same file without the suffix failed. We rejected the alternative of treating the suffix as sufficient placement proof in flat layouts: it makes the rule weaker for exactly the files whose role is clearest, and a team that wants a flat layer can still disable the rule for those paths with an override (ADR-0003).
